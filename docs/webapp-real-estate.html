Web App Real Buddy

Real Buddy is a real estate information lookup application integrated with an AI Chatbot for real estate consulting support. The web app is built using the Django framework, Bootstrap, and PostgreSQL. Below is a description of the main sections of the web app, including Models, Views, and key Templates.

1. Django Models

The database is built for this project with three main features: real estate search, recommendation system, and chatbot system.

- Below is the ERD (Entity-Relationship Diagram) of the real estate search application.

For the search feature, let's take a look at its database, which consists of two main parts. The first part includes data for administrative locations in Vietnam, consisting 3 tables. The second part covers real estate listings, consisting of 4 tables.

Ứng dụng Real Buddy là 1 ứng dụng tra cứu thông tin bất động sản và tích hợp Chatbot AI để hỗ trợ tư vấn bất động sản. Webapp được xây dựng với framework Django, Boostrap, Posgtgres SQL. Dưới đây là phần mô tả qua các phần chính của webapp gồm Models, Views, và các Templates chính.

Automated Data Crawling System

The system is built to automatically collect data from real estate websites and operate continuously. It helps in updating new real estate data sources. The following article will provide an overview of how the system operates.

  • Programming Language: Python
  • Tools: Selenium (Selenium Webdriver)

Overview of the System

- Main modules:
  • Real Estate Listings Scraping Module: Collect list links to real estate posts.
  • Detailed Real Estate Information Scraping Module: Collect detail info of real estate posts.
- Describe:

The real estate data collection system begins with the Real Estate Listings Scraping Module, which retrieves URLs of real estate listings. These URLs are then stored in a temporary queue referred to as "Info url" files. Once completed, the Detailed Real Estate Information Scraping Module runs to extract information from each real estate listing. The collected data includes JSON files (containing data fields), TXT files (containing HTML source code), and downloaded image files. Specific details will be described in the diagram.

The checkpoint file is a JSON file containing information such as the collection status, number of pages collected, and the last executed module. This allows us to resume the incomplete process without starting over in case of system errors.

After scraping and processing, the data is stored in a database. For a description of the database structure and integration with Django, please refer to the link here.

Hệ thống được xây dựng để thu thập dữ liệu từ các trang web bất động sản một cách tự động và hoạt động liên tục. Giúp cập nhật được các nguồn dữ liệu mới của bất động sản. Và bài viết dưới đây sẽ mô tả tổng quan về cách hoạt động của hệ thống.

  • Ngôn ngữ lập trình: Python
  • Công cụ: Selenium (Selenium Webdriver)

Tổng quan về hệ thống

- Thành phần chính:
  • Module cào đường dẫn: Thu thập các liên kết đến các bài đăng bất động sản.
  • Module cào dữ liệu chi tiết: Thu thập thông tin chi tiết từ các bài đăng.
- Mô tả:

Hệ thống thu thập dữ liệu bất động sản được hoạt động bắt đầu từ Module cào đường dẫn các bài đăng bất động sản sau đó được lưu trữ lại vào hàng chờ tạm gọi là các tệp tin "Info url". Sau khi hoàn thành thì Module cào dữ liệu chi tiết sẽ được chạy để lấy thông tin của các tin bất động sản dữ liệu được lưu trữ về gồm các tệp tin JSON (chứa các trường thông tin), txt (chứa mã nguồn html), các tệp hình ảnh tải về.
